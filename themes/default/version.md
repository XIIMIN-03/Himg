# Himg 版本信息

## 当前版本

- **版本号**：0.1
- **运行形态**：Docker / 单进程服务
- **数据存储**：SQLite + 本地目录 / WebDAV / S3

## 主要能力

- 图片上传后立即返回外链地址。
- AI 标签和 AI 审核在后台异步处理，不阻塞上传响应。
- 支持图片管理、标签编辑、隐藏控制、访问统计和向量搜索。
- 支持公告、主题、存储、AI、安全和通知配置。

## 部署入口

- 管理台端口：`6841 -> 8080`
- 配置来源：管理台配置 / 环境变量 / SQLite 数据库
- 默认主题目录：`themes/default`
